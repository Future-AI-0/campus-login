校园网登录 · Windows 单文件版

只需 CampusLogin.exe，无需 _internal 文件夹，也无需安装 Python。电脑需要 Microsoft Edge。
启动时会先解压运行依赖到系统临时目录，稍等数秒即可。
创建桌面快捷方式已移到后台。如果希望更快启动，使用精简目录版。

1. 双击 CampusLogin.exe，填写账号、密码，从固定列表选择运营商；修改立即保存。
2. “入口可达时静默自动登录”默认开启，每 15 秒检测校园网网卡联网状态及入口；已经联网不重复认证，需要登录时在后台认证。
3. 关闭窗口可继续在托盘运行。单击托盘图标打开窗口，右键可暂停、立即连接或退出。
4. 程序会在桌面创建或更新“校园网登录”快捷方式；快捷方式默认静默启动。

账号保存在 exe 旁的 .env；偏好保存在 settings.json，均不会写入临时解压目录。
已有 .env 可以与 exe 放在一起。GUI 优先读取 .env，缺失配置从 CAMPUS_USERNAME、CAMPUS_PASSWORD、CAMPUS_OPERATOR 环境变量读取。
移动 exe 后，手动从新位置运行一次即可更新快捷方式。

后台使用已保存的配置。“自动保存到本机”默认开启，修改账号、密码、运营商立即更新 .env。清空字段也会保存，避免使用旧凭据。
取消自动保存可临时填写其他账号，仍可点击“保存配置”手动保存。
失败按 60、120、240、300 秒的间隔重试；账号密码错误或要求验证码时会暂停。
成功后自动关闭认证浏览器。已在线时不再提交账号；热点能上网不代表校园网认证成功。
点击“取消”会暂停自动登录。右键托盘选择“退出”会清理浏览器并退出。
勾选“开机启动（登录 Windows 后）”即可在登录 Windows 后静默进入托盘；取消勾选移除启动项，无需管理员权限。新安装默认关闭。
移动 exe 后，从新位置运行一次即可更新已启用的启动项。

HTTP 555 表示门户要求重新跳转，不直接视为已在线；程序尝试通过校园网网卡获取新入口，支持网关的 HTTP 和 HTML/JavaScript 跳转。不修改系统路由或代理。
新入口的完整客户端参数保存于本机 settings.json，后续复用。
DNS 和 HTTPS 检测绑定校园网网卡及其 IPv4 地址，验证公网证书与 HTTP 200。探测超时、门户在线但外网未确认时显示“状态待确认”，不判为未登录。
已联网时不打开浏览器、不提交账号；一次探测失败继续检测，连续两轮未确认才重新检查门户。恢复后清除旧错误。
便携压缩包不包含个人账号、密码、.env 或 settings.json。
